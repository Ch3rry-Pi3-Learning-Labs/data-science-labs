# CH3RRY PI3 Learning Lab Review Checklist

## Structure

- [ ] Intended audience, prerequisites and learning outcomes are explicit.
- [ ] The table of contents links to every principal section.
- [ ] Section numbering and anchors are consistent.
- [ ] The notebook progresses from intuition to formal method to implementation.

## Mathematics

- [ ] Every symbol is defined before use.
- [ ] Important equations use local section-based numbering.
- [ ] Mathematical statements and derivations are correct.
- [ ] Plain-English readings explain the operation and purpose of key equations.
- [ ] A small worked example connects the notation to actual values.

## Code

- [ ] Reusable functions have type hints and NumPy-style docstrings.
- [ ] Functions have focused responsibilities.
- [ ] Array shapes and indexing conventions are explained.
- [ ] Input validation and numerical safeguards are proportionate.
- [ ] The complete implementation reuses the introduced functions.

## Communication and accessibility

- [ ] Acronyms are written out at first use.
- [ ] Jargon and prerequisites are explained.
- [ ] No concept is dismissed as obvious, trivial or easy.
- [ ] Colour is not the only carrier of meaning.
- [ ] Figures and outputs receive textual interpretations.

## Reproducibility and release

- [ ] A clean-kernel execution completes without errors.
- [ ] Randomness is reproducible where appropriate.
- [ ] Dependencies and data sources are documented.
- [ ] Links, anchors, images and filenames work.
- [ ] Claims do not exceed the evidence shown.
- [ ] Limitations and suggested next steps are included.
